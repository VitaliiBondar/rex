# Шаблони документів

Сюди кладуться `.docx`-шаблони для генерації документів застосунком (серверний
код, не публічний `public/`).

Перший шаблон: **повідомлення про призов**. Точні плейсхолдери в шаблоні й
бібліотека для їх заповнення узгоджуються, коли починаємо будувати сам
генератор — наразі директорія лише резервує місце.

ПІБ кандидата (`Candidate.fullName`) зберігається як "Прізвище Ім'я По
батькові" (три слова, де третє — по батькові, за потреби); в UI показуються
лише перші два слова (`displayName()` у `src/lib/format.ts`), але саме повне
значення буде джерелом для відмінювання через `shevchenko` при генерації
документів.
